# Email PDF Implementation Guide

**Created**: 2026-01-19  
**Status**: Planning Phase  
**Priority**: Medium (Long-Term Solution)

---

## Executive Summary

This document provides a detailed guide for implementing an automated email PDF delivery system. The system will send copies of PDFs to clients when they complete payments, ensuring they have their documents before the job is archived in the platform.

**Problem Solved**: Currently, completed job JSON files are deleted quickly after payment_2 completion (within one push). This ensures clients have their documents before archival, clearing any liability concerns.

---

## Requirements

### Email Types

#### 1. Payment 1 Completion Email (Links)
- **Trigger**: When `payment_1` event is processed
- **Content**: Thank you email with download links to:
  - Contract PDF
  - Invoice PDF
- **Delivery Method**: Email with clickable links (not attachments)
- **Purpose**: Immediate access to documents after first payment

#### 2. Payment 2 Completion Email (Attachments)
- **Trigger**: When `payment_2` event is processed
- **Content**: Thank you email with attached PDFs:
  - Contract PDF (attachment)
  - Invoice PDF (attachment)
  - Balance PDF (attachment)
- **Delivery Method**: Email with actual PDF attachments
- **Purpose**: Ensure client has all documents before job archival

---

## Current System Context

### PDF Generation
- **Location**: `assets/pdf/contract/`, `assets/pdf/invoice/`, `assets/pdf/balance/`
- **Format**: PDF files generated by `admin-push.yml` workflow using Google Docs API
- **Naming**: `kon-{job_id}.pdf`, `inv-{job_id}.pdf`, `bal-{job_id}.pdf`
- **Storage**: PDFs stored in repository, served via static hosting

### Event Processing
- **Workflow**: `user-exit-events.yml` processes payment events
- **Script**: `.github/scripts/orchestration/user_exit_events.py` updates JSON
- **Timing**: Events processed when workflow runs (after 10min inactivity or payment completion)

### Job Archival
- **Process**: After `payment_2`, `product.active=false` is set
- **Archival**: Next `admin-push.yml` workflow archives Stripe product and deletes JSON file
- **Timeline**: JSON file deleted within one push after payment_2 completion

## Implementation Options

### Option 1: Google OAuth + Gmail API (Recommended)

**Pros**:
- ✅ Already using Google OAuth for PDF generation
- ✅ OAuth refresh token flow already implemented
- ✅ Gmail API can send emails with attachments
- ✅ No additional service signup required

**Cons**:
- ⚠️ Requires Gmail API setup
- ⚠️ May have sending limits (but should be fine for low volume)

**Implementation**:
1. Use existing Google OAuth credentials
2. Add Gmail API scope to OAuth consent
3. Create email sending function in GitHub Actions workflow
4. Attach PDFs from repository to email

### Option 2: SendGrid / Mailgun / Resend

**Pros**:
- ✅ Dedicated email service (more reliable)
- ✅ Better deliverability
- ✅ More features (templates, analytics)
- ✅ Higher sending limits

**Cons**:
- ⚠️ Requires service signup and API key
- ⚠️ Additional cost (though free tiers available)
- ⚠️ Another service to manage

**Implementation**:
1. Sign up for email service
2. Add API key to GitHub Actions secrets
3. Create email sending function in workflow
4. Upload PDFs to service or attach from repository

### Option 3: AWS SES (Simple Email Service)

**Pros**:
- ✅ Very reliable
- ✅ Low cost
- ✅ Good deliverability

**Cons**:
- ⚠️ Requires AWS account setup
- ⚠️ More complex initial setup
- ⚠️ May be overkill for this use case

**Implementation**:
1. Set up AWS SES
2. Verify sending domain
3. Create IAM user with SES permissions
4. Add credentials to GitHub Actions secrets
5. Use boto3 (Python) to send emails

## Recommended Implementation: Google Gmail API

### Why Gmail API?

1. **Already Using Google OAuth**: We have OAuth refresh token flow set up for Google Docs API
2. **No Additional Service**: One less service to manage
3. **Sufficient for Volume**: Low volume of emails (one per payment completion)
4. **Familiar Stack**: Python scripts already using Google APIs

### Setup Steps

#### 1. Add Gmail API Scope

**File**: `api/google/auth.js` or OAuth consent screen configuration

Add Gmail API scope to OAuth consent:
```javascript
const SCOPES = [
  'https://www.googleapis.com/auth/documents',
  'https://www.googleapis.com/auth/drive',
  'https://www.googleapis.com/auth/gmail.send' // Add this
];
```

**Note**: Gmail API requires OAuth consent screen verification if sending to external users (clients). For low volume, may be able to use test mode initially.

#### 2. Create Email Sending Function

**New File**: `.github/scripts/orchestration/send_email.py`

```python
import os
import base64
from email.mime.multipart import MIMEMultipart
from email.mime.text import MIMEText
from email.mime.base import MIMEBase
from email import encoders
from google.oauth2.credentials import Credentials
from google_auth_oauthlib.flow import InstalledAppFlow
from google.auth.transport.requests import Request
from googleapiclient.discovery import build
import json

def get_gmail_service():
    """Get Gmail API service using refresh token."""
    creds = None
    # Load credentials from environment variable (set in workflow)
    creds_json = os.environ.get('GOOGLE_CREDENTIALS')
    if creds_json:
        creds_data = json.loads(creds_json)
        creds = Credentials.from_authorized_user_info(creds_data)
    
    # Refresh token if needed
    if creds and creds.expired and creds.refresh_token:
        creds.refresh(Request())
    
    return build('gmail', 'v1', credentials=creds)

def create_message_with_attachments(sender, to, subject, body_text, attachments):
    """Create email message with attachments."""
    message = MIMEMultipart()
    message['to'] = to
    message['from'] = sender
    message['subject'] = subject
    
    # Add body
    msg_body = MIMEText(body_text, 'plain')
    message.attach(msg_body)
    
    # Add attachments
    for file_path, filename in attachments:
        with open(file_path, 'rb') as f:
            part = MIMEBase('application', 'octet-stream')
            part.set_payload(f.read())
            encoders.encode_base64(part)
            part.add_header(
                'Content-Disposition',
                f'attachment; filename= {filename}',
            )
            message.attach(part)
    
    # Encode message
    raw_message = base64.urlsafe_b64encode(message.as_bytes()).decode('utf-8')
    return {'raw': raw_message}

def send_email(to_email, subject, body_text, attachments=None):
    """Send email via Gmail API."""
    service = get_gmail_service()
    
    # Get sender email from credentials
    sender_email = os.environ.get('GMAIL_SENDER_EMAIL', 'payments@august.style')
    
    # Prepare attachments (list of (file_path, filename) tuples)
    attachments = attachments or []
    
    # Create message
    message = create_message_with_attachments(
        sender_email,
        to_email,
        subject,
        body_text,
        attachments
    )
    
    # Send message
    sent_message = service.users().messages().send(
        userId='me',
        body=message
    ).execute()
    
    return sent_message

def send_payment_1_email(customer_email, customer_name, job_id, pdf_urls):
    """Send payment 1 completion email with download links."""
    subject = f"Thank you for your payment - {job_id}"
    
    body = f"""Dear {customer_name},

Thank you for completing your first payment. Your documents are available for download:

Contract: {pdf_urls['contract']}
Invoice: {pdf_urls['invoice']}

Please save these documents for your records. You will receive a final email with all documents attached after your final payment.

Best regards,
Sean August Horvath
"""
    
    # For payment_1, send email with links (no attachments)
    send_email(customer_email, subject, body)

def send_payment_2_email(customer_email, customer_name, job_id, pdf_paths):
    """Send payment 2 completion email with PDF attachments."""
    subject = f"Project Complete - Your Documents - {job_id}"
    
    body = f"""Dear {customer_name},

Thank you for completing your final payment. Your project is now complete!

Please find attached all your project documents:
- Contract
- Invoice
- Final Balance Statement

Please save these documents for your records.

Best regards,
Sean August Horvath
"""
    
    # Prepare attachments: (file_path, filename) tuples
    attachments = [
        (pdf_paths['contract'], f'contract-{job_id}.pdf'),
        (pdf_paths['invoice'], f'invoice-{job_id}.pdf'),
        (pdf_paths['balance'], f'balance-{job_id}.pdf'),
    ]
    
    # Send email with attachments
    send_email(customer_email, subject, body, attachments)
```

#### 3. Create Email Sending Function

**New File**: `.github/scripts/orchestration/send_email_resend.py`

```python
import os
import requests
from pathlib import Path

RESEND_API_KEY = os.environ.get('RESEND_API_KEY')
RESEND_API_URL = 'https://api.resend.com/emails'

def send_email_with_attachments(to_email, subject, body_text, attachments=None):
    """Send email via Resend API with attachments."""
    headers = {
        'Authorization': f'Bearer {RESEND_API_KEY}',
        'Content-Type': 'application/json',
    }
    
    # Prepare attachments
    attachment_data = []
    if attachments:
        for file_path, filename in attachments:
            file_content = Path(file_path).read_bytes()
            import base64
            attachment_data.append({
                'filename': filename,
                'content': base64.b64encode(file_content).decode('utf-8'),
            })
    
    payload = {
        'from': 'Payments <payments@august.style>',
        'to': [to_email],
        'subject': subject,
        'html': body_text.replace('\n', '<br>'),
        'attachments': attachment_data if attachment_data else None,
    }
    
    response = requests.post(RESEND_API_URL, json=payload, headers=headers)
    response.raise_for_status()
    return response.json()

def send_payment_1_email(customer_email, customer_name, job_id, pdf_urls):
    """Send payment 1 completion email with download links."""
    subject = f"Thank you for your payment - {job_id}"
    
    body = f"""Dear {customer_name},

Thank you for completing your first payment. Your documents are available for download:

<a href="{pdf_urls['contract']}">Download Contract</a>
<a href="{pdf_urls['invoice']}">Download Invoice</a>

Please save these documents for your records. You will receive a final email with all documents attached after your final payment.

Best regards,
Sean August Horvath
"""
    
    send_email_with_attachments(customer_email, subject, body)

def send_payment_2_email(customer_email, customer_name, job_id, pdf_paths):
    """Send payment 2 completion email with PDF attachments."""
    subject = f"Project Complete - Your Documents - {job_id}"

Please find attached all your project documents:
- Contract
- Invoice
- Final Balance Statement

Please save these documents for your records.

Best regards,
Sean August Horvath
"""
    
    attachments = [
```

## Implementation Notes

### Timing Considerations
- Emails sent during `user-exit-events.yml` workflow execution
- PDFs must exist in repository before email can attach them
- Consider if PDFs are guaranteed to exist at email sending time

### Fallback Options
- If email sending fails, log error but don't fail workflow
- Consider retry logic for failed emails
- Manual email sending option if automated fails

### Cost Considerations
- Gmail API: Free (within limits)
- Resend: Free tier (100 emails/day)
- AWS SES: Very low cost ($0.10 per 1000 emails)
