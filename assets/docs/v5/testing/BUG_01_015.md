### Change What UI Renders Based On State 

* **STATE 1:** User completes payment_1 checkout session successfully 
  
  + This page is shown this ONE time, and then never again because next login would send them to balance PDF

  + Triggers event that 
    - Adds timestamp to JSON for `state.client_status.payment_1` in batch update (**still needs to be fixed but see other bug report**)
    - Immediately direct user to `data.checkout_session_1.return_url` 
      `https://payments.august.style/uid-xxx-xxx?complete=payment_1?session_id={CHECKOUT_SESSION_ID}` 

  **STATE 1 PAGE VISUAL DESIGN AND COPY** 

  + Some kind of visual that makes them feel proud 
    - Encouraged, excited, forget they spent money 
    - A thank you, and then any next step details to be aware of 
  + Message that they will get an email for next payment 
    - Can map the job's JSON value `price2.pay_by` which is usually just "before launch" 
    - Download docs button for Contract and Invoice that *also* closes the browser (?)
  + SMALL button that says "You can pay your final balance now if you want -->" 
    - Not because we expect people to or are telling them to
    - But it feels like, given it is a payment platform, they should be able to if they happen to want for whatever reason 

* **STATE 2:** User completes payment_2 checkout session successfully 

  + This page is shown **FOREVER** 
    - Anytime the user logs in from now on 
    - It means all of `state.client_status` is filled in: `logged_in`, `contract_signed`, `invoice`, `payment_1`, `balance`, `payment_2` 
    - The user might never log in again, but if they did for whatever reason, this is the only state they should see and be able to navigate to 

  + Triggers event that 
    - Adds timestamp to JSON for `state.client_status.payment_2` in back update (**same note as above**)
    - Immediately redirects user to `data.checkout_session_2.return_url` 
      `https://payments.august.style/uid-xxx-xxx?complete=payment_2?session_id={CHECKOUT_SESSION_ID}` 

  **STATE 2 PAGE VISUAL DESIGN AND COPY** 

  + Hooray visual that they've completely paid for their `product.name` (mapped JSON values)
    - Similar happy vibe, let them know that they've paid off their entire service charge of `product.service_usd` (format $0.00)
    - "Thank you `customer.name`, `customer.title` of `customer.business`" 
  + Provide for them buttons to download their documents "Don't forget to grab copies now if you didn't already" 
    - CONTRACT PDF, INVOICE PDF, BALANCE PDF 
    - And some kind of "Email sean@august.style if you have any other questions about your service" 
    - "If you'd like to submit a review, please click here" or "email review@august.style" 

  + NOTE: that when I say "page" it is because I'm new to React/TS and am not confident on my wording about states and whatnot
